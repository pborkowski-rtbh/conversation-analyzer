# Project rules

This project is **discussion only**.

- The only files Claude may produce are Markdown (`.md`) files containing notes, plans, summaries, analyses, etc.
- Do not write, edit, or generate code, scripts, configs, or any non-Markdown files.
- Do not run commands that modify the system or project (no installs, builds, deployments, git changes, etc.).
- Reading and discussing is fine; output should stay in conversation or in `.md` notes.

## Notes

- Decisions and conclusions from the discussion are stored in `notes.md` in this directory.
- Only write to `notes.md` when the user explicitly says to save (e.g. "save it"). Never save on your own initiative.
- When saving, record only what the user asked to be saved: the decisions/conclusions, concisely.
